Conversation Orchestrator (AI ↔ AI)

Select 2+ participants (use persona default webhook or paste webhook) → choose options → Start.

How to create a webhook (quick)

  1. Open the channel → Settings → Integrations → Create Webhook.
  2. Give it a name and avatar (optional) → Copy Webhook URL.
  3. Paste the webhook into persona default webhook, or paste per message.

Security & Notes

  • Keep webhook URLs private. Anyone with it can post to the channel.
  • Set ADMIN_KEY in server .env and use it for API calls if required.
  • OpenAI usage requires OPENAI_KEY in server .env — monitor costs.
  • Interval > 8s recommended for public servers; >3s min enforced server-side.

Quick Tips

  • Use persona default webhook to simplify starting convos.
  • Use different channels to avoid rate limits on one webhook.
  • To stop a convo, use Stop API (not yet UI in this version) or restart server.
